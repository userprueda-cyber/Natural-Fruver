# THE THIRD ACTOR - documentary edit
Built with the video-use workflow (EDL of cuts, per-scene extract + lossless concat, 30 ms audio fades, captions applied last).
- `python tools/build.py [--preview]` rebuilds `edit/final.mp4` (needs ffmpeg with libass; set FFMPEG).
- Theme "Curtain Call": velvet/gold palette, warm grade, gold frame, curtain-open title, curtain-close end card.
- `theater_images/photo_*.jpg` are real theater photos from Wikimedia Commons (licences and authors in `theater_images/credits.json`, shown in the end credits). The older `0*_*.jpg` illustrations are only a fallback.
- Audio ID: 11-36-44 = Ms. Angela Gordon (used). 12-03-50 = Camilo Gonzalez (added as "A second voice" before the closing).
